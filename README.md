# MERN E-Commerce Store

A basic full-stack e-commerce web application built using the MERN stack (MongoDB, Express.js, React.js, and Node.js).

## Features

* User Registration
* User Login Authentication
* Product Listing
* Shopping Cart
* MongoDB Database Integration
* REST API Backend

## Tech Stack

### Frontend

* React.js
* React Router DOM
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
